# BeEF Termux Installer

[![Telegram Contact](https://img.shields.io/badge/Telegram-@cybe4-blue?style=for-the-badge&logo=telegram)](https://t.me/cybe4)

Script de instalação automatizada do **BeEF (Browser Exploitation Framework)** adaptado para correr nativamente no **Termux (Android)** sem interrupções de prompts e com correção automática de dependências nativas (Nokogiri, FFI e Sqlite3).

## 🚀 Requisitos

* **Termux** atualizado (via F-Droid).
* Pelo menos **1.5 GB** de espaço livre no armazenamento.
* Conexão à internet ativa.

## 📥 Instalação Rápida

Abra o seu Termux e execute:

```bash
pkg update && pkg install git -y
git clone [https://github.com/O_TEU_UTILIZADOR/O_TEU_REPO.git](https://github.com/O_TEU_UTILIZADOR/O_TEU_REPO.git)
cd Beef-install-termux
chmod +x install.sh
./install.sh
